## 01 / Featured project

### [Good Stuff](https://next-goodstuff.vercel.app/)

**Useful resources. A place to keep the good ones.**

A web app I built to help designers and developers discover, collect, and revisit useful resources—from design inspiration to development tools.

- **Discover:** Browse a curated collection of design and development resources.
- **Like:** Create a free account to like your favorites.
- **Bookmark:** Build your own list of resources to come back to. Guests can bookmark too—no account required.
